# terschellingify
Turn images in to Terschelling versions using LLM.

Note: this was meant for personal use only.

Should you want to use images generated by this, make sure you are allowed to use all input photos for your intended use.

## Developer set-up
### Local set-up
1. Create & activate local library using `uv`
2. Set google API key env var, like: `export GOOGLE_API_KEY='xxxx'`
3. `python app_frontend.py
4. Open app in browser

### Deployment

1. Create modal account
2. Set up modal locally using `modal token new`
3. Set Up Gemini API Key:
   Make sure you're logged in to Modal, then go to [modal.com/secrets/](https://modal.com/secrets/) and create a new secret:
   - Secret name: `gemini`
   - Add environment variable: `GOOGLE_API_KEY` = your Gemini API key
4. `modal deploy modal_wrapper`
